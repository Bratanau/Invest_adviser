Пошаговое руководство: как запустить приложение в Telegram (TMA)
Чтобы превратить этот веб-сервис в реальный Telegram Mini App, выполните следующие шаги:
Шаг 1. Запустите приложение локально и создайте HTTPS-туннель
Для локальной разработки понадобятся Node.js LTS и npm. В PowerShell из корневой папки проекта выполните:

```powershell
npm install
npm run dev
```

Сервер будет доступен на http://localhost:3000. Не закрывайте это окно терминала.

Telegram не может открыть localhost на вашем компьютере, поэтому во втором окне PowerShell запустите туннель. Например, установите Cloudflare Tunnel:

```powershell
winget install --id Cloudflare.cloudflared
```

После установки откройте новое окно PowerShell и выполните:

```powershell
cloudflared tunnel --protocol http2 --url http://localhost:3000
```

В выводе команды найдите временный адрес вида https://random-words.trycloudflare.com. Используйте его как Web App URL в шагах 3 и 4 ниже. Адрес меняется при перезапуске туннеля; после этого укажите новый URL в настройках бота. Для альтернативы можно установить ngrok и запустить `ngrok http 3000` (ngrok потребует аккаунт и настройку токена авторизации).

Оставляйте оба окна терминала запущенными, пока тестируете приложение. Остановка команды туннеля закроет публичный доступ. Туннель делает локальный сервер доступным из интернета — используйте его только для тестирования и не размещайте в проекте секреты или реальные пользовательские данные.

Для постоянного адреса разверните проект на облачном хостинге (например, Cloud Run, Render, Railway, Vercel или VPS с Nginx и Let's Encrypt) и используйте его HTTPS URL вместо адреса туннеля.
Шаг 2. Создайте Telegram-бота через @BotFather
Откройте Telegram и перейдите к официальному боту: @BotFather.
Отправьте команду:
Text
/newbot
Введите название бота (например, Голос Разума — Инвест-Аналитик).
Введите юзернейм бота, заканчивающийся на bot (например, MarketCalmerBot или SmartInvestReasonBot).
Сохраните выданный API Token вида 7123456789:AAH... (он понадобится бэкенду).
Шаг 3. Зарегистрируйте Mini App в @BotFather
В диалоге с @BotFather отправьте команду:
Text
/newapp
Выберите созданного бота из списка.
Введите название приложения (например, Голос Разума).
Введите краткое описание (например, Анализ новостей без шума и тренажер инвестора).
Загрузите иконку (640x360 px для превью и 1:1 для аватара).
В ответ на запрос Web App URL отправьте HTTPS-адрес из шага 1, например `https://random-words.trycloudflare.com`.
Придумайте короткое имя (short name), например: app или analyzer.
Вы получите прямую ссылку на запуск Mini App вида:
Text
https://t.me/MarketCalmerBot/app
Шаг 4. Настройте кнопку меню в боте (Menu Button)
Чтобы у пользователей прямо в окне чата с ботом всегда была кнопка вызова приложения:
В @BotFather отправьте команду:
Text
/setmenubutton
Выберите вашего бота.
Отправьте HTTPS-адрес из шага 1 (для локального тестирования — адрес туннеля).
Введите текст для кнопки (например: 📊 Открыть аналитик).
Шаг 5. Telegram WebApp SDK
Откройте Mini App по ссылке из Telegram, чтобы проверить его во встроенном браузере. В текущей сборке официальный Telegram WebApp SDK не подключен, а методы `Telegram.WebApp.ready()` и `Telegram.WebApp.expand()` не вызываются. Кнопка «Поделиться» использует URL-шлюз https://t.me/share/url; при наличии WebApp API она открывает ссылку через Telegram.
